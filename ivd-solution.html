IVD 行业流体控制的核心挑战

体外诊断（In Vitro Diagnostics, IVD）是对取自人体的血液、尿液、组织等样本进行体外分析的医学技术。从生化指标到肿瘤标志物，从血常规到分子检测，IVD 几乎覆盖临床所有疾病的筛查、诊断与疗效评估。

作为 IVD 仪器的"血液循环系统"，微型泵承担着样品的吸取分配、试剂的精密计量、反应杯/探针的清洗冲洗、废液的排除以及气路的真空压力供给，其精度、稳定性、寿命、耐化学性直接决定了仪器的检测准确度、检测速度与维护成本。

CORE FUNCTIONS

IVD 仪器中的六大流体功能

从样本进入仪器到检测完成、清洗复位的全流程，微型泵承担着"吸、推、注、洗、排、控"六大关键动作。

FUNCTION 01

样品吸取 Sample Aspiration

通过样本针/探针从样本杯中精确吸取微升级血液、尿液、血清等样本。要求吸量精确、无气泡、无交叉污染，是检测准确性的第一道关口。

注射泵 柱塞泵 隔膜负压泵
FUNCTION 02

试剂分注 Reagent Dispensing

将 R1/R2 试剂、底物、标记物、稀释液、缓冲液等以 µL 级精度分注至反应杯。是检测灵敏度与重复性的核心保证，CV 通常需控制在 1% 以内。

注射泵 微量齿轮泵 蠕动分注泵
FUNCTION 03

清洗冲洗 Probe & Cuvette Wash

清洗探针内外壁防止 Carry-over 交叉污染，清洗反应杯/微孔板去除未结合物。供液与抽液协同工作，决定每一个测试的稳定输出。

蠕动泵 隔膜液泵
FUNCTION 04

废液排除 Waste Removal

将反应残液、清洗废液从反应区彻底抽走至废液桶。耐多种试剂腐蚀、长期稳定运行是关键诉求，涉及到每一个反应单元的复位。

蠕动泵 隔膜抽吸泵
FUNCTION 05

气路控制 Pneumatic Control

提供稳定真空驱动液体抽吸、提供正压推送鞘液或微流控液滴、实现微孔板气压清洗与气密性检测。脉动低、响应快是关键指标。

隔膜气泵 真空泵 压电气泵
FUNCTION 06

流体输送 Bulk Fluid Transfer

大体积稀释液、系统液、鞘液等从储液瓶持续输送至工作位。要求流量稳定、低脉动、长寿命，是仪器后台流路的基础动力。

齿轮泵 蠕动泵
